## 🏛️ 7대 핵심 서비스
1. **ME 페이스 분석**: 얼굴 비율/중안부/황금비 정밀 측정 (미등록 시 스탠바이 모드)
2. **추구미 진단 리포트**: 12개 영역 정밀 진단 및 ME ➔ BE 격차 분석
3. **30일 컨설팅 로드맵**: 캘린더 인터페이스 우선 뷰 & 0% 체크리스트
4. **비포 & 애프터**: 사용자 직접 사진 등록 및 목표 비교 트래커
5. **제휴 패키지 혜택**: 청담 헤어살롱, 메이크업, 피부클리닉 VIP 패키지
6. **아뜰리에 피드**: 에디토리얼 비주얼 룩북
7. **스타일 아카이브**: 개인화된 뷰티 에셋 보관함
